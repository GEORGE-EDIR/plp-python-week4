# Grade Reporter & Bug Hunt

This repository contains my Week 4 Python assignment.

* `grade_reporter.py` - Uses a for loop and if/elif/else conditions to calculate grades, pass/fail counts, and the average score.
* `bug_hunt.py` - Fixes three bugs in a while loop program and calculates the sum of numbers from 1 to 5.
* `screenshots/` - Contains screenshots showing both programs running successfully.

The hardest bug to find in Part B was the loop condition because it did not produce an error message. The program ran normally but gave the wrong answer, which showed that the loop was stopping before it included the number 5.
